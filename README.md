# Tic-Tac-Toe

A simple console-based Tic-Tac-Toe game written in Java as a project for my **CS142 class**.

## Description

This project implements a two-player Tic-Tac-Toe game using a 3×3 grid. Players take turns entering the row and column where they want to place their mark.

The game automatically checks for:

- Horizontal winning combinations
- Vertical winning combinations
- Diagonal winning combinations
- A full board resulting in a tie
- Invalid input
- Positions that are already occupied

Player X goes first, followed by Player O. The game continues until one player wins or the board is full.

## Features

- Console-based interface
- Two-player gameplay
- Input validation
- Win detection
- Tie detection
- 3×3 game board
- Separate methods for game logic and board management

## Technologies

- Java
- Java Scanner
- 2D Arrays
- Methods
- Loops
